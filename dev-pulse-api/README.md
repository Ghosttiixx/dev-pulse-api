# DevPulse API

Lightweight RESTful API service built with Node.js and Express.

## Features
- 🚀 Express server with ES Modules
- ⚡ Health-check & status monitoring endpoints
- 🛡️ CORS enabled & modular architecture

## Getting Started

```bash
# Clone repository
git clone [https://github.com/YOUR_USERNAME/dev-pulse-api.git](https://github.com/YOUR_USERNAME/dev-pulse-api.git)

# Install dependencies
npm install

# Run in development mode
npm run dev
